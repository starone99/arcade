# 온천 마을 스테이지 도구

- `logic.js` — 물 흐름 규칙(수문, 얼음 녹이기, 구름, 색 섞임 포함), 1~10번과 마을별 튜토리얼(11, 21 … 81번), 섞기, 코치용 경로 계산.
  게임 `index.html`의 `// LOGIC START ~ END` 구간과 같은 코드입니다.
- `gen.js` — 나머지 82개 스테이지 생성기. 마을마다 해당 기믹을 넣고,
  얼음·낙엽이 덮인 시작 상태에서 풀리는지 / 섞었을 때 이미 풀려 있지 않은지 / 수문·높낮이 블록이 실제로 필요한지 검증합니다.
- `sortgen.js` — 마을 안에서 쉬운 순서로 정렬합니다.
- `verify.js` — 손으로 만든 18개 스테이지 검증.

```bash
node verify.js
node gen.js && node sortgen.js   # generated.json 재생성
```

생성 결과는 게임 파일 안의 `GENERATED` 배열에 그대로 들어가 있습니다. 다시 만들면 퍼즐이 바뀌어 기존 기록과 맞지 않습니다.
