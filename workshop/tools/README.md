# 작은 공방 스테이지 도구

- `logic.js` — 부품 회전(돌리기·세우기·눕히기), 설계도 칸에 맞는 자리 찾기, 받쳐 붙이기·밀어 넣기 규칙. 게임 `index.html`의 `// LOGIC START ~ END` 구간과 같은 코드입니다.
- `models.js` — 집, 나무, 등대, 배, 자동차, 풍차 등 16가지 복셀 모형을 크기·색을 바꿔 만듭니다.
- `gen.js` — 모형을 부품으로 나누고, 작업대 규칙 아래에서 조립 순서가 실제로 있는지 확인합니다(그 순서가 안내의 정답). 규칙이 처음 나오는 판은 규칙을 무시하고 위에서부터 끼우면 막히는지도 확인합니다.

```bash
node gen.js   # stages.json 재생성
```
