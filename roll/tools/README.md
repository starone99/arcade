# 귤 상자 굴리기 스테이지 도구

- `logic.js` — 굴리기 규칙(연잎, 버튼·다리, 얼음 미끄러짐, 유자)과 BFS 최단 경로 탐색. 게임 `index.html`의 `// LOGIC START ~ END` 구간과 같은 코드입니다.
- `gen.js` — 상자가 돌아다닌 자리를 길로 칠하고 끝에서 선 자리를 구멍으로 삼아 판을 만든 뒤, BFS로 최단 수(=목표 횟수)를 구합니다.
  정원별 기믹이 실제로 답을 바꾸는지(기믹을 평범한 돌로 바꿨을 때와 비교)도 확인합니다.

```bash
node gen.js   # stages.json 재생성
```
