# 카피바라 이삿짐 스테이지 도구

- `logic.js` — 짐 회전(돌리기·세우기·눕히기), 떨어뜨려 넣기, 그릇·책 규칙, 갇힌 빈칸 계산. 게임 `index.html`의 `// LOGIC START ~ END` 구간과 같은 코드입니다.
- `gen.js` — 상자를 폴리큐브로 나눈 뒤, 아래부터 하나씩 떨어뜨려 정확히 채울 수 있는 순서가 있는지 확인합니다. 그 순서가 게임 안내(코치)의 정답이 됩니다.
- `verify.js` — 모든 판을 정답 순서대로 다시 넣어 봅니다.

```bash
node gen.js && node verify.js   # levels.json 재생성 + 검증
```
